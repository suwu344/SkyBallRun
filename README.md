# Sky Ball Run

Godot 4 rolling-ball parkour prototype.

## Run

Double-click `play_runner.bat`, or open the project in Godot 4.7+.

## Controls

- A / D or Left / Right: steer
- W / Up / Space / left mouse: boost
- Space / R / Enter after game over: restart
- Esc: quit

The project contains four sequential levels, free-fall exit behavior, finish distance HUD, and separate gameplay/end music.
